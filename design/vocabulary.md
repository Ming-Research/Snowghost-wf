Decision: The document is an arena: its nodes live in one `Box<Slots<Node>>` named by `NodeId`, a `u32` index, with parent, first and last child and sibling links held as indices, because Whitefoot never stores a reference, so a tree is either owned or linked by indices, and the parser, the HTML tree construction rules and script need to reach any node by its identity and to insert, move and remove nodes anywhere, which an owned tree cannot give, instead of an owned tree of nodes.

Decision: Layout lengths are `LayoutUnit`, an `i32` counting 1/64 of a CSS pixel, with the geometry types built on it and one rounding from a CSS length at computed-value time, because fixed point adds and compares exactly, keeps a layout independent of floating-point rounding and evaluation order, and still spans about 33 million pixels, as Blink's layout unit does, instead of `f32` or `f64` lengths.

Decision: Tag, attribute and property names are atoms, `u32` indices into one atom table in which every name the renderer knows has a fixed index generated ahead of time, because matching, the cascade and tree construction compare names on every element and an atom turns each comparison into an integer comparison and each known name into a constant, instead of comparing name bytes or hashes at each use.

Decision: A document's character data lives in one UTF-8 byte arena per document, named by `u32` spans, because every stage but script reads UTF-8 and the HTML and CSS preprocessing rules already replace what UTF-8 cannot encode; provisionally, until script lands, when the arena is to widen to WTF-8 so that a lone surrogate a script stores survives, as Servo stores DOM strings, instead of UTF-16 text, which every stage but script would convert.

Decision: An element's computed style is a small struct of group identifiers, each computed-value group (box, text, font, background, border, margin and padding, position) interned in a per-group table by one sequential pass after the style stage, because equal styles then share storage, a style comparison compares identifiers and inheritance copies one, and the sequential pass costs at most 4.6 percent of the parallel style stage on the three measured real pages ([style measurement](../research/investigations/concurrency/DESIGN.md#style-measurement)), instead of a full computed style per element or interning split into parallel per-partition tables.

Rejected:
- An owned document tree: rejected because the tree construction rules move and reparent nodes (the adoption agency and foster parenting) and script holds node identities, neither of which an owned tree expresses without stored references.
- UTF-16 document text: rejected because only script reads UTF-16, while tokenizing, matching, shaping and line breaking read UTF-8.
