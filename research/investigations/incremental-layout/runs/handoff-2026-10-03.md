## Material corrections raised before stopping

These corrections were discussed with the owner. They are recorded here so
that earlier provisional tree/research wording is not mistaken for settled
architecture. No further implementation was made after the stop instruction.

- **Q77 needs reassessment.** Background presence controls which inline
  rectangles are reported, not a demonstrated dependency of text preparation,
  line breaking or element placement. The current shared dirty path recomputes
  too much. Existing falsifiers show stale output if the change is ignored;
  they do not prove relayout is necessary. Read-only analysis found the
  rectangles serve the CSSOM `getClientRects` oracle, not an established paint
  interface. Consider independent report projection from retained geometry;
  its representation, cost and independent-browser checks remain unvalidated.
- **Q78 does not yet fairly evaluate the approved persistent-ID option.**
  Primary interface commit `ec77b1963230210881c6778ff5b3cd3fa33eea87` already
  selected temporary value mapping, citing concern that retained intern tables
  would grow during a session. Implementer commit
  `5f023fc50abb87cd645a6d73e5f31c260a8a5f80` followed that interface. The Q68 text
  and later approval record `bc4f266186ef988753fd35d4752b967771cd4015` remained
  on persistent IDs. No supporting long-session/reclamation comparison was
  found. The current experiment compares temporary tables with direct value
  comparison, not the approved persistent scheme. A claim that persistent
  identity necessarily adds serialization needs reassessment against the
  style stage's existing interning dependencies. The newly requested
  read-only reassessment was interrupted at the owner's stop.

## Evidence archive

`handoff-2026-10-03-index.json` lists the four local archive parts, SHA256
values, the archive digest, incoming/current PR heads and the captured
component worktrees. The raw archive is deliberately outside Git; its local
location is `build/x5/handoff-2026-10-03-evidence/` in the original workspace.
Copy all four parts with the index when moving machines. Reconstruct in order:

```sh
cat build/x5/handoff-2026-10-03-evidence/handoff-2026-10-03-evidence.tar.gz.part-* > /tmp/x5-handoff-evidence.tar.gz
mkdir -p /tmp/x5-handoff-evidence
tar -xzf /tmp/x5-handoff-evidence.tar.gz -C /tmp/x5-handoff-evidence
```

The archive contains generated source/probes, fixtures, provenance, raw stdout,
stderr, incomplete and failed attempts, and the small renderer comparison.
`MANIFEST.json` records each included file's original path, size and SHA256.
Downloaded fonts/packages, native/compiler binaries and disposable caches are
omitted from Git; their local copies are preserved, and existing provenance
records identify the measured binaries and inputs. Tracked source histories
remain in Git rather than being replaced by this archive. The combined branch
has not received a new build, test or completion review.
