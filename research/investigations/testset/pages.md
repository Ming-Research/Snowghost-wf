# Snowghost test set: proposed web-app pages (research, 2026-10-12)

Ranking source: Chrome UX Report top origins, global list, via the community mirror
github.com/zakird/crux-top-lists, file `data/global/202608.csv.gz` (August 2026; byte-identical
to `current.csv.gz` on 2026-10-12, etag d394d6b7...). Ranks are buckets: an origin's value N means
"in the top N origins" (1000, 5000, 10000, 50000, 100000, 500000, 1000000); the list is unordered
within a bucket. Lookup was an exact `https://<host>` match against that file.

Load checks were made on 2026-10-12 in the Claude desktop built-in browser (Chromium, US IP, no
sign-in, JS executed, 4-10 s wait). "flex/grid" counts are elements with computed display
flex/grid after load, as a rough layout-heaviness signal. Two caveats apply to every row:
(a) cookie or consent walls were only checked from a US IP; EU IPs commonly add them (YouTube,
Reddit, Amazon, Dailymotion, Pinterest); (b) shop and social pages localize by IP (the pane resolved
to Seattle), so snapshots must pin location or run from a fixed egress.

## Categories not filled as asked, and alternatives considered

- **Mail: not filled with a real mail client.** Every ranked mail origin (mail.google.com, outlook.live.com/office.com, mail.yahoo.com, mail.aol.com, mail.proton.me, app.tuta.com, icloud.com/mail, mail.zoho.com) redirects or lands on a login form. Checked: Yahoo goes to a 133-node sign-in form; iCloud shows a 298-node sign-in page; Tuta renders blank; Proton `mail.proton.me` is login. So the two rows above are product landing pages, which test marketing layout, not an inbox/thread/compose UI. No ranked public demo exists: demo.roundcube.net is not in the top 1M, and the web search found no live no-login Roundcube or SnappyMail demo. The practical fix is to self-host a static fixture (e.g. a Roundcube or Mailpit instance with fixed seeded mail) as an out-of-ranking page, which needs an owner decision because it breaks the "ranked origin" rule.
- **Admin dashboards: public demos are not in the ranking.** Well-known demos are absent from the top 1M or dead: play.grafana.org (not ranked; now serves a stub/redirect to a marketing dashboards page), demo.sentry.io, demo.metabase.com, demo.elastic.co, demo.adminlte.io, demo.tabler.io, preview.pro.ant.design (all not ranked). The four chosen are public-by-design dashboards on ranked origins; all have login links but need no login.
- **Document editing:** docs.google.com (1k) redirects to Google sign-in at the root. A published-to-web Google Doc (`/document/d/e/2PACX-.../pub`) would be login-free, but no stable public doc URL was found in search, so none is proposed. Notion pages: www.notion.so is 1M bucket and public pages live on notion.site (not ranked); www.notion.com/help is static docs, not an editor. excalidraw.com (100k) loads with no login but is a canvas app with 327 DOM nodes, so low value for layout testing.
- **Social:** x.com (1k) and Instagram/Facebook gate content behind login; Threads (www.threads.com, 1k) loads logged-out (https://www.threads.com/@zuck, 1501 nodes, 372 flex/grid) but with a login prompt and a fast-moving feed, kept as an alternative. mastodon.social is in the 500k bucket only. Pinterest (1k) not checked in a browser.
- **Shopping:** Etsy (1k) returns 403 to curl and a blank document (9 nodes) in the browser (bot protection); excluded. Best Buy times out for curl (not browser-checked); eBay and AliExpress were not browser-checked. Walmart and Amazon may challenge automated snapshots from datacenter IPs.
- **Video:** Dailymotion (1k) shows a cookie banner and renders only ~420 nodes; excluded. Twitch directory (https://www.twitch.tv/directory, 1k) loads logged out (1.6k nodes) but is live-stream churn, so high volatility; alternative. Netflix landing (1k) is a sign-up marketing page; alternative. YouTube watch pages are the only video app with a rich layout.
- Out of scope but noted: the browser pane blocks reddit.com, so Reddit was checked only with curl.

## Method notes

- Exact ranks are not available in CrUX; only the bucket (1k/5k/10k/50k/100k/500k/1M). Ties are within the same bucket and unordered.
- Snapshot stability hint: pin location/egress, language and viewport; prefer URLs with a frozen date range (Plausible) or immutable content (Bluesky post, HackMD note, all-time-top Reddit).
- The `stackblitz.com` (500k), `codepen.io` (50k), `codesandbox.io` (500k), `miro.com` (50k) and `trello.com` (5k) origins are ranked candidates for later document/work-management rounds; they were not browser-checked.
