# W7 — narrow topology reads and existing stride windows

**HYPOTHETICAL:** S1 `Paged` and S2 `columns`; the layout declaration lives
in `design.md`. `SequenceNode`, `SequenceCursor` and the two semantic outputs
are the existing renderer types. `links`, `own` and `total` occupy separate
physical groups within a page. The read helper returns exactly one scalar;
no SequenceNode temporary is formed. Its cost does not depend on inlining.

```wf
fn left_at(left: &[u32], slot: u64) -> value: u32 reads(left) {
  if slot < left^.len {
    return left^[slot];
  }
  return 4294967295_u32;
}

fn copy_topology(left: &[u32], height: &[u32], output: &[u64]) -> result: unit reads(left), reads(height), writes(output) {
  let count = output^.len;
  for (i in 0_u64..count) {
    if i < height^.len {
      let child = left_at(left: left, slot: i);
      let child_wide = cvt::<u32, u64>(child);
      let height_wide = cvt::<u32, u64>(height^[i]);
      set output^[i] = child_wide +wrap height_wide;
    }
  }
  return unit;
}

fn topology_pass(nodes: &Paged<SequenceNode>, output: &[u64]) -> result: unit reads(nodes.rows.len), reads(nodes.columns.links.left), reads(nodes.columns.links.height), writes(output) {
  let count = nodes^.rows.len;
  copy_topology(left: &nodes^.columns.links.left[0_u64..count], height: &nodes^.columns.links.height[0_u64..count], output: output);
  return unit;
}

fn fill_window(output: &[u64], value: u64) -> result: unit writes(output) {
  let count = output^.len;
  for (k in 0_u64..count) {
    set output^[k] = value;
  }
  return unit;
}

fn sixteen_per_row(output: &[u64], rows: u64) -> result: unit writes(output) contract {
  requires rows <= 1048576_u64;
  requires output^.len == rows * 16_u64;
} {
  for (u in 0_u64..rows) {
    let start = u * 16_u64;
    let end = start + 16_u64;
    if end <= output^.len {
      fill_window(output: &output^[start..end], value: u);
    }
  }
  return unit;
}
```

The topology loop reads immutable columns and writes output[i]. The helper
may read the whole left column because it overlaps no written root; a helper
reading that entire column in a loop writing it would require a narrower
element argument. No predecessor dependence exists. In `sixteen_per_row`,
exact checked endpoint images identify `[16*u, 16*u+16)`; for i < j,
`16*i+16 <= 16*j`. Existing PAR-2's range rule supplies separation. This last
function introduces **no hypothetical syntax at all**.

Two views of the same field still alias. Passing both `&nodes.rows[i]` for
writing and `&nodes.columns.links.left[i]` for reading to one call is rejected
by EFF-5; choosing different spellings is not a split. Projections of a cold
field in the same group are strided; only declaring a separate physical group
removes the cold bytes from that group's cache-line stream. A paged descriptor
may be wider than today's contiguous range ABI; code-size and extra-argument
costs remain to measure.

Original: `slot_cursor` (30 lines) and `slot_links` (26) already avoid copying the two
SequenceOutput values by field-narrow helpers. The file contains 1,106 lines;
the generic `slot_read` is 28 lines. The new improvement is one general
projection plus constant-depth lookup, not a claim that today's field-narrow
read copies a full node. No fresh byte-size measurement of the record was made.
