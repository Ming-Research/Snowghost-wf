# W3 — sparse scatter, one establishment and two consumers

**HYPOTHETICAL:** only the `Paged` owner and the `columns` places at the call
site. `validate_order`, `translate` and `set_widths` are also today's Whitefoot.
Their ordinary RANGE contracts, including the proof-only inverse parameter,
are intentionally visible. This is a reusable-fact example, not an opaque
proof-carrying type.

`position` is the traversal's semantic inverse (the ordinal of an entry in
this pass), stored with its payload. The producer must have written it while
building that traversal. The verifier below establishes the relation from
ordinary runtime input once, rejecting an out-of-range slot or wrong inverse.
For duplicates at k and q, one position cannot equal both k and q: at least
one comparison fails. No unchecked constructor or trusted `unique` annotation
appears. If no semantic inverse exists, allocating/constructing one is an
additional cost, not something S2 supplies.

```wf
struct ScatterRow {
  position: u64;
  parent: u64;
  y: i64;
  width: i64;
}

fn validate_order(order: &[u64], position: &[u64]) -> result: Result<u64, unit> reads(order), reads(position) contract {
  ensures when Ok(value: checked): forall bounded(k in 0_u64..order^.len): order^[k] < position^.len;
  ensures when Ok(value: checked): forall inverse(k in 0_u64..order^.len): position^[order^[k]] == k;
} {
  let count = order^.len;
  let limit = position^.len;
  for (
    k in 0_u64..count,
    invariant forall bounded_prefix(q in 0_u64..k): order^[q] < limit,
    invariant forall inverse_prefix(q in 0_u64..k): position^[order^[q]] == q
  ) {
    let at = order^[k];
    if at >= limit {
      return Err<u64, unit>(error: unit);
    }
    if position^[at] != k {
      return Err<u64, unit>(error: unit);
    }
  }
  return Ok<u64, unit>(value: count);
}

fn translate(order: &[u64], position: &[u64], y: &[i64], delta: i64) -> result: unit reads(order), writes(y) contract {
  requires position^.len == y^.len;
  requires forall inverse(k in 0_u64..order^.len) when order^[k] < y^.len: position^[order^[k]] == k;
} {
  let count = order^.len;
  for (
    k in 0_u64..count,
    apart(i, j) {
    }
  ) {
    let at = order^[k];
    if at < y^.len {
      set y^[at] = y^[at] +sat delta;
    }
  }
  return unit;
}

fn set_widths(order: &[u64], position: &[u64], parents: &[u64], available: &[i64], widths: &[i64], inset: i64) -> result: unit reads(order), reads(parents), reads(available), writes(widths) contract {
  requires position^.len == widths^.len;
  requires forall inverse(k in 0_u64..order^.len) when order^[k] < widths^.len: position^[order^[k]] == k;
} {
  let count = order^.len;
  for (
    k in 0_u64..count,
    apart(i, j) {
    }
  ) {
    let at = order^[k];
    if at < widths^.len {
      if at < parents^.len {
        let parent = parents^[at];
        if parent < available^.len {
          let room = available^[parent] -sat inset;
          set widths^[at] = imax(room, 0_i64);
        }
      }
    }
  }
  return unit;
}

fn two_passes(order: &[u64], position: &[u64], parents: &[u64], available: &[i64], y: &[i64], widths: &[i64], delta: i64, inset: i64) -> result: Result<unit, unit> reads(order), reads(position), reads(parents), reads(available), writes(y), writes(widths) {
  if position^.len != y^.len {
    return Err<unit, unit>(error: unit);
  }
  if position^.len != widths^.len {
    return Err<unit, unit>(error: unit);
  }
  let checked = validate_order(order: order, position: position);
  match checked {
    Ok(value: done) => {
      translate(order: order, position: position, y: y, delta: delta);
      set_widths(order: order, position: position, parents: parents, available: available, widths: widths, inset: inset);
      return Ok<unit, unit>(value: unit);
    }
    Err(error: failure) => {
      return Err<unit, unit>(error: unit);
    }
  }
}

fn projected_passes(order: &[u64], rows: &Paged<ScatterRow>, available: &[i64], delta: i64, inset: i64) -> result: Result<unit, unit> reads(order), reads(rows.rows.len), reads(rows.columns.position), reads(rows.columns.parent), reads(available), writes(rows.columns.y), writes(rows.columns.width) {
  let count = rows^.rows.len;
  let result = two_passes(order: order, position: &rows^.columns.position[0_u64..count], parents: &rows^.columns.parent[0_u64..count], available: available, y: &rows^.columns.y[0_u64..count], widths: &rows^.columns.width[0_u64..count], delta: delta, inset: inset);
  return result;
}
```

Proof trace: `validate_order`'s two loop invariants establish its successful
postconditions. At the Ok arm they become active RANGE facts. Neither
consumer writes `order` or `position`, so both calls can discharge the same
inverse requirement. In either certified loop, assume `order[i] == order[j]`:
the two instances of the inverse make that single position equal i and j,
contradicting i != j. Same-slot read/modify/write of y is covered. The width
pass reads an immutable owner-width snapshot, so it introduces no sibling
write-to-read edge. EFF-5 must reject using widths itself as available.

The two consumers touch different output columns and may overlap under PAR-1
after validation. The validator's early rejection makes its shown loop
sequential: this is **extra validation order**, not a renderer dependency.
An already verified traversal producer should publish the same postconditions
and eliminate the scan. This mock keeps the scan to expose the real fact
establishment, and records the remaining proof/abstraction cost in F3.

Facts cannot be stored through an arbitrary outer function without contracts,
survive a mutation of the inverse, or establish bounds in ordinary OP-4;
the runtime bounds branches therefore stay in the consumers. A logically
injective list of handles with two generations of the same slot is not safe.
Validate projected physical slots against the frozen store, not whole handles.
