# W1 — stable per-owner ordered entries

**HYPOTHETICAL:** `Paged<T>`, its `rows` place and `paged_*` are S1;
`columns` and field grouping are S2. Everything else uses ordinary Whitefoot
declarations, call-local references, named arguments and effect rows.

This is an alternate layout-module source excerpt, not a standalone program.
`Flow`, `SequenceCursor`, `SequenceOutput`, `LayoutError`,
`BoundaryVisits`, the empty-value constructors and `join_output` have their
existing definitions in `renderer/layout/`. `EntrySequence` below replaces
that module's storage declaration. The **existing AVL library bodies** remain
`sequence_parent`, `sequence_repair`, `sequence_rotate_left/right`,
`sequence_balance`, `sequence_insert_at`, `sequence_extract_first`,
`sequence_remove_at`, `sequence_rank`, `boundary_rank` and `boundary_set`. They call the storage
adapters below; their `reads(sequence.span)` rows remain valid because those
adapters check the same span. No AVL behavior is supplied by a primitive.
`boundary_node` and `boundary_output` are the existing counted wrappers over
`sequence_node` and `slot_output`. The generation wrapper is new library code.

The span is a fixed logical ceiling here, not a directory-tree depth. Handles
are scoped by an owner directory slot and its generation; a caller validates
that owner before entering this per-owner API. The example never reuses slots;
retirement increments generations for the remove/lookup protocol. Admitting
reuse would also require `insert_before` to accept and validate a
`LocalEntryId` instead of its current no-reuse raw slot. On generation
exhaustion a tombstone is permanently quarantined, never wrapped.

```wf
struct EntryCell {
  links: SequenceCursor;
  own: SequenceOutput;
  total: SequenceOutput;
  payload: Flow;
  generation: u64;
}

nocopy struct EntrySequence {
  nodes: Paged<EntryCell>;
  root: u32;
  allocated: u32;
  span: u32;
}

struct LocalEntryId {
  slot: u32;
  generation: u64;
}

fn new_sequence() -> made: EntrySequence pure {
  let nodes = paged_new::<EntryCell>();
  return EntrySequence(nodes: move nodes, root: no_index, allocated: 0_u32, span: 1073741824_u32);
}

fn sequence_node(sequence: &EntrySequence, slot: u32) -> made: SequenceCursor reads(sequence.nodes), reads(sequence.span) {
  let at = cvt::<u32, u64>(slot);
  if slot < sequence^.span {
    if at < sequence^.nodes.rows.len {
      return sequence^.nodes.columns.links[at];
    }
  }
  return vacant_cursor();
}

fn sequence_write(sequence: &EntrySequence, slot: u32, node: SequenceCursor) -> result: unit reads(sequence.span), writes(sequence.nodes) {
  let at = cvt::<u32, u64>(slot);
  if slot < sequence^.span {
    if at < sequence^.nodes.rows.len {
      set sequence^.nodes.columns.links[at] = node;
    }
  }
  return unit;
}

fn slot_output(pages: &Paged<EntryCell>, slot: u32, span: u32, own: Bool) -> made: SequenceOutput reads(pages) {
  let at = cvt::<u32, u64>(slot);
  if slot < span {
    if at < pages^.rows.len {
      if pages^.columns.links[at].live {
        if own {
          let value = pages^.columns.own[at];
          set value.count = 1_u64;
          set value.events = pages^.columns.links[at].own_events;
          return value;
        } else {
          let value = pages^.columns.total[at];
          set value.count = pages^.columns.links[at].total_count;
          set value.events = pages^.columns.links[at].total_events;
          return value;
        }
      }
    }
  }
  return empty_output();
}

fn slot_store_output(pages: &Paged<EntryCell>, slot: u32, span: u32, output: &SequenceOutput, own: Bool) -> result: unit reads(output), writes(pages) {
  let at = cvt::<u32, u64>(slot);
  if slot < span {
    if at < pages^.rows.len {
      if own {
        set pages^.columns.own[at] = output^;
        set pages^.columns.links[at].own_events = output^.events;
      } else {
        set pages^.columns.total[at] = output^;
        set pages^.columns.links[at].total_events = output^.events;
        set pages^.columns.links[at].total_count = output^.count;
      }
    }
  }
  return unit;
}

fn sequence_payload(sequence: &EntrySequence, slot: u32) -> made: Flow reads(sequence.nodes), reads(sequence.span) {
  let held = sequence_node(sequence: sequence, slot: slot);
  let at = cvt::<u32, u64>(slot);
  if held.live {
    if at < sequence^.nodes.rows.len {
      return sequence^.nodes.columns.payload[at];
    }
  }
  return Flow::Close(block: no_index);
}

fn insert_before(sequence: &EntrySequence, before: u32, item: Flow, output: SequenceOutput, visits: &BoundaryVisits) -> result: Result<LocalEntryId, LayoutError> writes(sequence), writes(visits) {
  if sequence^.allocated >= 1073741824_u32 {
    return too_large::<LocalEntryId>();
  }
  if before != no_index {
    let target = sequence_node(sequence: sequence, slot: before);
    if target.live {
    } else {
      return inconsistent::<LocalEntryId>();
    }
  }
  let fresh = sequence^.allocated;
  let at = cvt::<u32, u64>(fresh);
  if sequence^.nodes.rows.len != at {
    return inconsistent::<LocalEntryId>();
  }
  let rank = boundary_rank(sequence: sequence, slot: before, visits: visits);
  let yes = True();
  let links = SequenceCursor(left: no_index, right: no_index, parent: no_index, height: 1_u32, live: yes, own_events: output.events, total_events: output.events, total_count: 1_u64);
  let node = EntryCell(links: links, own: output, total: output, payload: item, generation: 0_u64);
  let node_slot = paged_push::<EntryCell>(store: &sequence^.nodes, value: node);
  let old_root = sequence^.root;
  let inserted = sequence_insert_at(sequence: sequence, root: old_root, rank: rank, added: fresh, parent: no_index, visits: visits);
  set sequence^.root = inserted;
  set sequence^.allocated = fresh + 1_u32;
  let id = LocalEntryId(slot: fresh, generation: 0_u64);
  return Ok<LocalEntryId, LayoutError>(value: id);
}

fn remove(sequence: &EntrySequence, id: LocalEntryId, visits: &BoundaryVisits) -> removed: Bool writes(sequence), writes(visits) {
  let at = cvt::<u32, u64>(id.slot);
  if at >= sequence^.nodes.rows.len {
    return False();
  }
  if sequence^.nodes.columns.generation[at] != id.generation {
    return False();
  }
  let held = sequence_node(sequence: sequence, slot: id.slot);
  if held.live {
  } else {
    return False();
  }
  let rank = boundary_rank(sequence: sequence, slot: id.slot, visits: visits);
  let old_root = sequence^.root;
  let remainder = sequence_remove_at(sequence: sequence, root: old_root, rank: rank, visits: visits);
  set sequence^.root = remainder;
  if at < sequence^.nodes.rows.len {
    let previous = sequence^.nodes.columns.generation[at];
    if previous < 18446744073709551615_u64 {
      set sequence^.nodes.columns.generation[at] = previous + 1_u64;
    }
  }
  return True();
}

fn select_entry(sequence: &EntrySequence, rank: u64) -> id: Option<LocalEntryId> reads(sequence) {
  let cursor = sequence^.root;
  let remaining = rank;
  let limit = cvt::<u32, u64>(sequence^.allocated);
  for (step in 0_u64..limit) {
    let held = sequence_node(sequence: sequence, slot: cursor);
    if held.live {
    } else {
      return None<LocalEntryId>();
    }
    let left = sequence_node(sequence: sequence, slot: held.left);
    if remaining < left.total_count {
      set cursor = held.left;
    } else if remaining == left.total_count {
      let at = cvt::<u32, u64>(cursor);
      if at < sequence^.nodes.rows.len {
        let generation = sequence^.nodes.columns.generation[at];
        let selected = LocalEntryId(slot: cursor, generation: generation);
        return Some<LocalEntryId>(value: selected);
      }
      return None<LocalEntryId>();
    } else {
      set remaining = remaining -sat left.total_count;
      set remaining = remaining -sat 1_u64;
      set cursor = held.right;
    }
  }
  return None<LocalEntryId>();
}

fn select_event(sequence: &EntrySequence, event: u64) -> (slot: u32, offset: u64) reads(sequence) {
  let cursor = sequence^.root;
  let remaining = event;
  let limit = cvt::<u32, u64>(sequence^.allocated);
  for (step in 0_u64..limit) {
    let held = sequence_node(sequence: sequence, slot: cursor);
    if held.live {
    } else {
      return no_index, 0_u64;
    }
    let left = sequence_node(sequence: sequence, slot: held.left);
    if remaining < left.total_events {
      set cursor = held.left;
    } else {
      set remaining = remaining -sat left.total_events;
      if remaining < held.own_events {
        return cursor, remaining;
      }
      set remaining = remaining -sat held.own_events;
      set cursor = held.right;
    }
  }
  return no_index, 0_u64;
}
```

The required AVL dependency is the changed leaf → its search/repair ancestors;
one owner's root mutation orders edits to that owner. Other owners have no
shared root or allocator cursor in their source state. Select depends on the
preceding node's child choice. Initial bulk construction is W5, not repeated
insertion.

The library still owes its ordinary AVL invariants: reachable nodes are live,
parents/children agree, count/weight caches are exact, rotations preserve
inorder order and transplant metadata rather than payloads. Its original
`sequence_remove_at` tombstones the removed cursor and transplants the
successor's links, which is why a two-child deletion preserves the successor's
identity. S1 establishes none of these facts. A list oracle should check
insert-before at first/middle/end, two-child deletion, out-of-range rank,
stale IDs, and event weights spanning nested blocks. None was executed here.

Each logical index access loses the recursive directory descent, but AVL
search remains O(log live entries); page growth can still copy directory
words. One page allocation contains all EntryCell groups; no separate payload or
generation directory is needed. The generation check costs an extra metadata load at the API boundary,
not at every internal topology read. The fixed-depth source guard is replaced
with an allocated-node bound; a corrupt cycle yields no result, not a claimed
valid selection.

Size baseline: `insert_before` 32 lines, `remove` 11, `sequence_select` 24;
`slot_read` 28 and `slot_write` 47, in the 1,106-line original `sequence.wf`.
