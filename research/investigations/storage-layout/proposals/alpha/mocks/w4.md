# W4 — dense paragraphs, independently growing owned pieces

**HYPOTHETICAL:** S1 `Paged`, `paged_new` and `paged_push`. Paragraphs own
their pieces. The decoded scalar stream stands in for the output of text
decoding/shaping; repeated scalars and inserted break markers make the output
length data-dependent. Within one paragraph the last emitted piece depends
on earlier whitespace, so that short loop is ordered. Different paragraphs
share neither pieces nor allocation metadata in source state.

```wf
struct Piece {
  scalar: u32;
  advance: i64;
}

nocopy struct Paragraph {
  source: Box<Array<u32>>;
  pieces: Paged<Piece>;
  width: i64;
  retired: Bool;
}

fn prepare_one(paragraph: &Paragraph, space_advance: i64) -> ok: Bool reads(paragraph.source), writes(paragraph.pieces), writes(paragraph.width) {
  let fresh = paged_new::<Piece>();
  set paragraph^.pieces = move fresh;
  set paragraph^.width = 0_i64;
  let count = paragraph^.source.inner.len;
  let preceding_space = True();
  for (k in 0_u64..count) {
    let scalar = paragraph^.source.inner[k];
    let space = scalar == 32_u32;
    let repeated = band(space, preceding_space);
    if repeated {
    } else {
      if paragraph^.pieces.rows.len >= 1073741824_u64 {
        return False();
      }
      let advance = if space {
        give space_advance;
      } else {
        give 1_i64;
      }
      let piece = Piece(scalar: scalar, advance: advance);
      let placed = paged_push::<Piece>(store: &paragraph^.pieces, value: piece);
      set paragraph^.width = paragraph^.width +sat advance;
      if scalar == 10_u32 {
        if paragraph^.pieces.rows.len >= 1073741824_u64 {
          return False();
        }
        let marker = Piece(scalar: 0_u32, advance: 0_i64);
        let inserted = paged_push::<Piece>(store: &paragraph^.pieces, value: marker);
      }
    }
    set preceding_space = space;
  }
  return True();
}

fn prepare_context(paragraphs: &Paged<Paragraph>, space_advance: i64) -> ok: Bool writes(paragraphs) {
  let count = paragraphs^.rows.len;
  let good = True();
  for (i in 0_u64..count) {
    if paragraphs^.rows[i].retired {
    } else {
      let ready = prepare_one(paragraph: &paragraphs^.rows[i], space_advance: space_advance);
      set good = band(good, ready);
    }
  }
  return good;
}
```

PAR-2's outer affine row i owns every piece below it. Growth of
`paragraphs[i].pieces` touches no other paragraph and does not grow the outer
paragraph directory. The helper's early return returns to its iteration;
the outer counted body still reaches its binder update. Its only cross-row
write is the permitted associative `band` accumulator. The scalar width
parameter is a value captured before the loop, avoiding the historical
unwritten-field survey problem. S1 grants no append to a shared piece pool.

S1 saves relocation on repeated growth and directory trees, but still has at
least one live allocation unit for a nonempty paragraph's pieces. A normal
slab allocator may coalesce tiny pages; that is not a source-level proof or
a demonstrated contention improvement. A proposed shared region cursor passed
to `prepare_one` would overlap all iterations and is rejected. Reset currently
frees the previous pages; retaining spare pages is a separate measurable
library policy, not needed to prove this mock.
