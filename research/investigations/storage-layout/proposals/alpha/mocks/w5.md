# W5 — document-order build, close-time index, bottom-up owners

**HYPOTHETICAL:** S1 `Paged` and its constructors/append. The shown record
fields can be grouped by S2 into topology, leaf transfer and retained output.
`SequenceOutput`, `empty_output` and `join_output` are the existing semantic
transfer library from `sequence.wf`; it supplies the same preflight/domain
conditions as today's renderer, not a new associative kernel operation.

Input is a balanced document-order event stream with an implicit context
root. Open/Close surround nested blocks; Leaf carries the prepared leaf
transfer. Each owner appends direct entries in document order. Close seals
its local AVL directly in final slot order and records its event weight in
its parent's already allocated entry. Owner lookup remains flat at any depth.

```wf
enum BuildEvent {
  Open();
  Leaf(output: SequenceOutput);
  Close();
}

struct BuildEntry {
  child: u64;
  left: u64;
  right: u64;
  parent: u64;
  height: u32;
  direct_count: u64;
  weight: u64;
  total: u64;
  leaf: SequenceOutput;
}

nocopy struct BuildOwner {
  parent: u64;
  parent_entry: u64;
  opening: u64;
  entries: Paged<BuildEntry>;
  root: u64;
  output: SequenceOutput;
}

const absent: u64 = 18446744073709551615_u64;

fn build_owner(parent: u64, parent_entry: u64, opening: u64) -> made: BuildOwner pure {
  let entries = paged_new::<BuildEntry>();
  let output = empty_output();
  return BuildOwner(parent: parent, parent_entry: parent_entry, opening: opening, entries: move entries, root: absent, output: output);
}

fn build_entry(child: u64, leaf: SequenceOutput) -> made: BuildEntry pure {
  return BuildEntry(child: child, left: absent, right: absent, parent: absent, height: 1_u32, direct_count: 1_u64, weight: 1_u64, total: 1_u64, leaf: leaf);
}

fn bulk(nodes: &[BuildEntry], base: u64, parent: u64) -> (root: u64, events: u64, height: u32) writes(nodes) {
  let count = nodes^.len;
  if count == 0_u64 {
    return absent, 0_u64, 0_u32;
  }
  let middle = count / 2_u64;
  if middle >= count {
    return absent, 0_u64, 0_u32;
  }
  let next = middle + 1_u64;
  let index = base +sat middle;
  let right_base = index +sat 1_u64;
  let (left, before, left_height) = bulk(nodes: &nodes^[0_u64..middle], base: base, parent: index);
  let (right, after, right_height) = bulk(nodes: &nodes^[next..count], base: right_base, parent: index);
  set nodes^[middle].left = left;
  set nodes^[middle].right = right;
  set nodes^[middle].parent = parent;
  let taller = imax(left_height, right_height);
  let height = taller +sat 1_u32;
  set nodes^[middle].height = height;
  set nodes^[middle].direct_count = count;
  let prefix = before +sat nodes^[middle].weight;
  let total = prefix +sat after;
  set nodes^[middle].total = total;
  return index, total, height;
}

fn seal(owner: &BuildOwner) -> events: u64 writes(owner.entries), writes(owner.root) {
  let count = owner^.entries.rows.len;
  let (root, total, height) = bulk(nodes: &owner^.entries.rows[0_u64..count], base: 0_u64, parent: absent);
  set owner^.root = root;
  return total;
}

fn build(events: &[BuildEvent]) -> result: Result<Paged<BuildOwner>, unit> reads(events) {
  let count = events^.len;
  if count >= 1073741823_u64 {
    return Err<Paged<BuildOwner>, unit>(error: unit);
  }
  let owners = paged_new::<BuildOwner>();
  let root = build_owner(parent: absent, parent_entry: absent, opening: absent);
  let root_slot = paged_push::<BuildOwner>(store: &owners, value: move root);
  let current = root_slot;
  for (k in 0_u64..count) {
    if current >= owners.rows.len {
      return Err<Paged<BuildOwner>, unit>(error: unit);
    }
    match events^[k] {
      Open() => {
        let entry = owners.rows[current].entries.rows.len;
        if entry >= 1073741824_u64 {
          return Err<Paged<BuildOwner>, unit>(error: unit);
        }
        if owners.rows.len >= 1073741824_u64 {
          return Err<Paged<BuildOwner>, unit>(error: unit);
        }
        let child = build_owner(parent: current, parent_entry: entry, opening: k);
        let child_slot = paged_push::<BuildOwner>(store: &owners, value: move child);
        if current >= owners.rows.len {
          return Err<Paged<BuildOwner>, unit>(error: unit);
        }
        let empty = empty_output();
        let node = build_entry(child: child_slot, leaf: empty);
        if owners.rows[current].entries.rows.len >= 1073741824_u64 {
          return Err<Paged<BuildOwner>, unit>(error: unit);
        }
        let stored = paged_push::<BuildEntry>(store: &owners.rows[current].entries, value: node);
        set current = child_slot;
      }
      Leaf(output: leaf_output) => {
        if owners.rows[current].entries.rows.len >= 1073741824_u64 {
          return Err<Paged<BuildOwner>, unit>(error: unit);
        }
        let node = build_entry(child: absent, leaf: leaf_output);
        let stored = paged_push::<BuildEntry>(store: &owners.rows[current].entries, value: node);
      }
      Close() => {
        let parent = owners.rows[current].parent;
        let parent_entry = owners.rows[current].parent_entry;
        if parent >= owners.rows.len {
          return Err<Paged<BuildOwner>, unit>(error: unit);
        }
        let total = seal(owner: &owners.rows[current]);
        if parent_entry >= owners.rows[parent].entries.rows.len {
          return Err<Paged<BuildOwner>, unit>(error: unit);
        }
        set owners.rows[parent].entries.rows[parent_entry].weight = total +sat 2_u64;
        set current = parent;
      }
    }
  }
  if current != root_slot {
    return Err<Paged<BuildOwner>, unit>(error: unit);
  }
  if root_slot >= owners.rows.len {
    return Err<Paged<BuildOwner>, unit>(error: unit);
  }
  let total = seal(owner: &owners.rows[root_slot]);
  if total != count {
    return Err<Paged<BuildOwner>, unit>(error: unit);
  }
  return Ok<Paged<BuildOwner>, unit>(value: move owners);
}

fn entry_weight(nodes: &[BuildEntry], slot: u64) -> weight: u64 reads(nodes) {
  if slot < nodes^.len {
    return nodes^[slot].total;
  }
  return 0_u64;
}

fn reduce_entries(owners: &Paged<BuildOwner>, nodes: &[BuildEntry], root: u64, output: &[SequenceOutput]) -> result: SequenceOutput reads(owners), reads(nodes), writes(output) {
  if root >= nodes^.len {
    return empty_output();
  }
  let left_slot = nodes^[root].left;
  let right_slot = nodes^[root].right;
  let before = entry_weight(nodes: nodes, slot: left_slot);
  let after = before +sat nodes^[root].weight;
  let count = output^.len;
  if before >= after {
    return empty_output();
  }
  if after > count {
    return empty_output();
  }
  let left = reduce_entries(owners: owners, nodes: nodes, root: left_slot, output: &output^[0_u64..before]);
  let right = reduce_entries(owners: owners, nodes: nodes, root: right_slot, output: &output^[after..count]);
  let child = nodes^[root].child;
  let own = nodes^[root].leaf;
  if child < owners^.rows.len {
    let start = before + 1_u64;
    let end = after - 1_u64;
    if start <= end {
      let entries = &owners^.rows[child].entries;
      let length = entries^.rows.len;
      let nested_root = owners^.rows[child].root;
      let nested = reduce_entries(owners: owners, nodes: &entries^.rows[0_u64..length], root: nested_root, output: &output^[start..end]);
      set own = nested;
    }
  }
  set own.count = 1_u64;
  set own.events = nodes^[root].weight;
  let prefix = join_output(left: &left, right: &own);
  let total = join_output(left: &prefix, right: &right);
  if before < output^.len {
    set output^[before] = own;
  }
  return total;
}

fn publish_totals(owners: &Paged<BuildOwner>, reduced: &[SequenceOutput], root_output: SequenceOutput) -> result: unit reads(reduced), writes(owners) {
  let count = owners^.rows.len;
  for (i in 0_u64..count) {
    let opening = owners^.rows[i].opening;
    if opening < reduced^.len {
      set owners^.rows[i].output = reduced^[opening];
    } else {
      set owners^.rows[i].output = root_output;
    }
  }
  return unit;
}
```

The build's source-order chain is the stack/current-owner state: an event's
owner and a Close weight depend on preceding Opens/Closes. Bulk construction
does not impose repeated AVL insertion; median halves use disjoint ranges
and only the parent's total waits. An implementation should schedule ready
close-time seals independently of unrelated later events; the shown `seal`
call operates inside the document walk and its broad owner path may prevent
that overlap. This is a remaining scheduling/expression cost (F7), not an
algorithmic need to serialize unrelated owners.

Reduction has no global level barrier or global counter. Left and right
subtrees and a nested owner's interior write disjoint output slices; PAR-1
can overlap the calls. Their parent combines results in the defined semantic
order. The scratch output is separate from immutable owners, so no helper
reads a whole root that the same parallel traversal writes. A later dense
publication loop writes owners[i] and reads only immutable reductions; no
injective scatter is needed. It runs after the root result is available.

The code models zero-strut block wrappers (`own = nested`); the renderer's
`block_output` must lift nested transfers for real CSS, just as today. Invalid
shape branches in the reducer are unreachable for a successful `build`;
accepting arbitrary externally supplied topology would require an explicit
validator/error-returning reducer. Neither S1 nor S2 proves tree validity.
