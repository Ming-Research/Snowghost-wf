# W8 — one pass allocation, recursive fill, several readers

**HYPOTHETICAL:** only S1 at the retained input (`Paged<BuildOwner>` from
W5). The event buffer and its lifetime are **already expressible** using
Box<Array<Event>>. A paged event buffer can use the same logical ranges if
contiguous reservation is undesirable, but is not automatically cheaper.
No region primitive or returned borrow is needed.

The event is a small owned description (kind, owner, stable entry), not a
copied paragraph or SequenceOutput. Event weights come from W5's sealed
index. Open and synthesized Close enclose the nested owner's event slice.

```wf
struct Event {
  kind: u8;
  owner: u64;
  entry: u64;
}

fn fill_entries(owners: &Paged<BuildOwner>, owner: u64, root: u64, output: &[Event]) -> ok: Bool reads(owners), writes(output) {
  if owner >= owners^.rows.len {
    return False();
  }
  let nodes = &owners^.rows[owner].entries;
  if root >= nodes^.rows.len {
    return output^.len == 0_u64;
  }
  let left = nodes^.rows[root].left;
  let right = nodes^.rows[root].right;
  let child = nodes^.rows[root].child;
  let count = nodes^.rows.len;
  let before = entry_weight(nodes: &nodes^.rows[0_u64..count], slot: left);
  let after = before +sat nodes^.rows[root].weight;
  let length = output^.len;
  if before >= after {
    return False();
  }
  if after > length {
    return False();
  }
  let first = fill_entries(owners: owners, owner: owner, root: left, output: &output^[0_u64..before]);
  let last = fill_entries(owners: owners, owner: owner, root: right, output: &output^[after..length]);
  let middle = True();
  if child < owners^.rows.len {
    let start = before + 1_u64;
    let end = after - 1_u64;
    if start <= end {
      set output^[before] = Event(kind: 0_u8, owner: owner, entry: root);
      let nested = owners^.rows[child].root;
      set middle = fill_entries(owners: owners, owner: child, root: nested, output: &output^[start..end]);
      if end < output^.len {
        set output^[end] = Event(kind: 2_u8, owner: owner, entry: root);
      } else {
        return False();
      }
    } else {
      return False();
    }
  } else {
    set output^[before] = Event(kind: 1_u8, owner: owner, entry: root);
  }
  let edges = band(first, last);
  return band(edges, middle);
}

fn count_leaves(events: &[Event]) -> count: u64 reads(events) {
  let count = 0_u64;
  let length = events^.len;
  for (i in 0_u64..length) {
    if events^[i].kind == 1_u8 {
      set count = count +wrap 1_u64;
    }
  }
  return count;
}

fn maximum_depth(events: &[Event]) -> maximum: u64 reads(events) {
  let depth = 0_u64;
  let maximum = 0_u64;
  let length = events^.len;
  for (i in 0_u64..length) {
    if events^[i].kind == 0_u8 {
      set depth = depth +sat 1_u64;
      set maximum = imax(maximum, depth);
    } else if events^[i].kind == 2_u8 {
      set depth = depth -sat 1_u64;
    }
  }
  return maximum;
}

fn pass(owners: &Paged<BuildOwner>) -> result: Result<u64, unit> reads(owners) {

```

The fill's ranges are left `[0,before)`, the current event at before, the
nested interval and Close, and right `[after,length)`. Every formed range has
explicit bounds. No sibling uses a shared append length. Siblings can run
under PAR-1; each reader begins after fill and borrows the same event array.
`count_leaves` permits a `+wrap` reduction; `maximum_depth` keeps document order
because each depth is the prefix balance of preceding Open/Close events in
this implementation. A parallel prefix algorithm is a library alternative,
not a storage capability. A real layout stateful walk similarly carries flow
state, not an allocator dependency.

`reduced` demonstrates another scratch owner in the same pass and calls W5's
bottom-up algorithm. A caller that needs retained totals publishes them
before leaving the pass, using W5's dense `publish_totals`; this read-only
diagnostic pass returns a scalar and deliberately retains neither array.
Ordinary scope release on success and error drops the scratch. There is one
event materialization, regardless of the number of event readers.

This still pays filled-array initialization followed by overwrite, and
separate allocations for unrelated scratch arrays. It does not assert that
an unsafe uninitialized range or a general heterogeneous region already
exists. Address stability is immaterial for a fixed-size event buffer; adding
paging here solely for uniformity would add a directory load without a need.
