# W6 — private build, page publication, rebased handles, retirement

**HYPOTHETICAL:** S1's consuming `paged_adopt`, row-granule query and S2
projections. W5 builds the private subtree; this mock shows the storage
publication step. `Parcel` represents a general stored node with owned bytes
and both an owner link and a sibling link, not a renderer-specific kernel
type. Local and retained identities are distinguished explicitly. Every
identity-bearing field is visited; bytes do not contain encoded handles.
Real renderer transfers, pieces and route records must supply their own
equally explicit relocation visitors.

The raw `vacant_parcel` function-kind argument uses FN-5, not a closure.
Adoption calls it for padding, so noncopy payloads are supported and every
logical slot remains initialized. Empty Paged byte owners allocate nothing.

```wf
enum Link {
  None();
  Local(slot: u64, generation: u64);
  Kept(slot: u64, generation: u64);
}

nocopy struct Parcel {
  parent: Link;
  next: Link;
  bytes: Paged<u8>;
  live: u8;
  generation: u64;
}

fn vacant_parcel() -> made: Parcel pure {
  let bytes = paged_new::<u8>();
  let absent = Link::None();
  return Parcel(parent: absent, next: absent, bytes: move bytes, live: 0_u8, generation: 0_u64);
}

fn rebase_link(link: Link, local_live: &[u8], local_generation: &[u64], kept_live: &[u8], kept_generation: &[u64], base: u64) -> result: Result<Link, unit> reads(local_live), reads(local_generation), reads(kept_live), reads(kept_generation) {
  match link {
    None() => {
      let absent = Link::None();
      return Ok<Link, unit>(value: absent);
    }
    Local(slot: at, generation: expected) => {
      if at >= local_live^.len {
        return Err<Link, unit>(error: unit);
      }
      if at >= local_generation^.len {
        return Err<Link, unit>(error: unit);
      }
      if local_live^[at] != 1_u8 {
        return Err<Link, unit>(error: unit);
      }
      if local_generation^[at] != expected {
        return Err<Link, unit>(error: unit);
      }
      if base > 1073741824_u64 {
        return Err<Link, unit>(error: unit);
      }
      let room = 1073741824_u64 - base;
      if at >= room {
        return Err<Link, unit>(error: unit);
      }
      let rebased = base + at;
      let final = Link::Kept(slot: rebased, generation: expected);
      return Ok<Link, unit>(value: final);
    }
    Kept(slot: at, generation: expected) => {
      if at >= kept_live^.len {
        return Err<Link, unit>(error: unit);
      }
      if at >= kept_generation^.len {
        return Err<Link, unit>(error: unit);
      }
      if kept_live^[at] != 1_u8 {
        return Err<Link, unit>(error: unit);
      }
      if kept_generation^[at] != expected {
        return Err<Link, unit>(error: unit);
      }
      return Ok<Link, unit>(value: link);
    }
  }
}

fn rewrite_links(links: &[Link], local_live: &[u8], local_generation: &[u64], kept_live: &[u8], kept_generation: &[u64], base: u64) -> ok: Bool reads(local_live), reads(local_generation), reads(kept_live), reads(kept_generation), writes(links) {
  let good = True();
  let count = links^.len;
  for (i in 0_u64..count) {
    let changed = rebase_link(link: links^[i], local_live: local_live, local_generation: local_generation, kept_live: kept_live, kept_generation: kept_generation, base: base);
    match changed {
      Ok(value: rebased) => {
        set links^[i] = rebased;
      }
      Err(error: failure) => {
        let no = False();
        set good = band(good, no);
      }
    }
  }
  return good;
}

fn retire_one(row: &Parcel) -> result: unit writes(row) {
  if row^.live == 1_u8 {
    let empty = paged_new::<u8>();
    set row^.bytes = move empty;
    set row^.parent = Link::None();
    set row^.next = Link::None();
    set row^.live = 0_u8;
    let previous = row^.generation;
    if previous < 18446744073709551615_u64 {
      set row^.generation = previous + 1_u64;
    }
  }
  return unit;
}
```

The private build and its preparation touch no retained payload. Rebasing is
dense affine-index work; it reads immutable liveness/generation columns and
writes independent parent/next columns. The two rewrite calls can overlap.
Every reference into held has ended before its consuming adoption. The aligned
base is determined from the retained length before publication; no other
mutation of that store may intervene. Source/target layout identity is a
type/layout property of `Paged<Parcel>`: B and the physical layout are fixed
uniquely by that concrete type on the selected target, so both instances match.
Adoption returns exactly this smallest aligned base and sets len to base+count,
not merely to some aligned position.

Publication has a real ownership boundary: the parent root/route must not
name private slots until the pages and rebased links exist. `publish` returns
the base for the caller to patch **one preflighted external seam**. The caller
must validate that seam, collect the removed subtree and its unique slot list,
and validate its inverse before any retained mutation. The inverse buffer is
sized to the final target length base+count, and removal preflight additionally
checks every removed slot is below old; appended slots are never retirement
targets. It then adopts, swaps the seam, and calls `retire_selected`; no fallible semantic step follows the
first retained write. The removed set must be descendant-closed, and no
surviving link may target it. Generation checks catch stale handles, but do
not repair a dangling graph or prove this splice policy. These are library
preconditions, matching the original private splice-plan/route-patch phase.

Retirement's whole-row helper is a call through **one selected element**, the
form RANGE-5 admits. `position` is a separate immutable validation buffer;
it must not be stored inside the rows being retired. Duplicate removal IDs
would violate the inverse and cannot justify concurrent drops. The helper
destroys owned bytes once and leaves the slot and generation metadata as
tombstones. Exhausted generations cannot be reused. Reclaiming an empty page
requires retaining enough generation state that reuse cannot resurrect an old
handle; this proposal keeps its page while its slot namespace is live.

This mock deliberately exposes two costs: all private identity edges must be
rebased once, and page-aligned adoption can add a nearly empty page per small
splice. There is no retained-prefix payload copy, but directory growth can
copy pointer words. `paged_adopt` also has a source-level whole-target effect;
unrelated adoptions into one target cannot run concurrently without a further
reserved-range interface, which is not smuggled into this proposal.
