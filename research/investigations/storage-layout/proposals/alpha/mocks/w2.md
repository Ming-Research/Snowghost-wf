# W2 — one entry, ancestor summaries, direct later origins

**HYPOTHETICAL:** S1 `Paged` and S2 `columns`. `Boundary` below models an
ordinary fixed-strut boundary, retaining height, baseline and intrinsic width
so a zero-height baseline change cannot incorrectly stop propagation. This
does not model float/clear or margin changes that the original preflight
refuses. Such a change is outside this mock's accepted input, not a silent
fallback.

Library interface used below: `repair_entry_path(entries: &EntrySequence,
slot: u32, output: Boundary) -> result: Boundary writes(entries)` is W1's
AVL ancestor repair (`boundary_set`, followed by its root-output read), with
Boundary substituted for the full transfer. It updates only cached summaries
and returns the owner's new summary. `EntrySequence` owns the index and no
child owner payloads. This sequential algorithm is not a new storage feature.

An owner's direct `order` and `position` are a snapshot for this update pass;
`position[order[k]] == k`. Their construction/validation is accounted for,
not assumed to be a persistent type invariant. `sequence_rank` is the existing parent-link lookup from
`renderer/layout/sequence.wf`, also used through W1's adapters. `translate_suffix` establishes the inverse once
through W3's validator and writes only direct origins. Entries naming nested
blocks are anchors; descendants are not rewritten.

fn same_boundary(first: Boundary, second: Boundary) -> same: Bool pure {
  let h = first.height == second.height;
  let b = first.baseline == second.baseline;
  let low = first.min_width == second.min_width;
  let high = first.max_width == second.max_width;
  let size = band(h, b);
  let widths = band(low, high);
  return band(size, widths);
}

fn translate_suffix(order: &[u64], position: &[u64], y: &[i64], first: u64, delta: i64) -> result: Result<unit, unit> reads(order), reads(position), writes(y) {
  if first > order^.len {
    return Err<unit, unit>(error: unit);
  }
  if position^.len != y^.len {
    return Err<unit, unit>(error: unit);
  }
  let valid = validate_order(order: order, position: position);
  match valid {
    Ok(value: checked) => {
      suffix_write(order: order, position: position, y: y, first: first, delta: delta);
      return Ok<unit, unit>(value: unit);
    }
    Err(error: failure) => {
      return Err<unit, unit>(error: unit);
    }
  }
}

fn propagate_boundary(owners: &Paged<Owner>, first_owner: u64, first_entry: u32, output: Boundary, displacement: i64) -> result: Result<unit, unit> writes(owners) {
  let owner = first_owner;
  let entry = first_entry;
  let outgoing = output;
  let delta = displacement;
  let count = owners^.rows.len;
  for (depth in 0_u64..count) {

The ancestor loop has a real dependency: the parent entry consumes the
child's new boundary. The count bound detects a malformed cycle rather than
pretending that a fixed depth of thirty is sufficient. Each iteration forms
a fresh borrow; it never retains one across changing the selected owner.
Direct suffix translations are independent. The shown translations can
precede the summary repair because this fixed-strut summary does not read
origins; the next ancestor waits for both because either may affect its
observable result. No whole-owner context is passed into the certified loop.

**Remaining friction:** snapshot construction is O(number of direct entries)
and the explicit validator is a serial read pass. It is not the original
O(log n + changed suffix) locality claim. The proposed production library
must derive the inverse while constructing a necessary traversal, or retain
a valid public inverse for the duration of a pass; neither paging nor
generations proves an AVL traversal injective. This is F3, a condition on the
recommendation, not a solved compiler property. Errors here report malformed
input; this function is not transactional across already completed ancestors.
