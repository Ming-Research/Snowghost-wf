# W7 — field projection across a helper boundary

HYPOTHETICAL: C1/C2. `Links` is the existing small topology/weight group; `Entry`
also has the large leaf/total Summary groups. Copying `Links` is intentional.
No path in this mock produces an owned whole Entry merely to select its field.

Source lines: 24. Original: `slot_cursor`, `slot_output`,
`slot_store_output`, `SequenceNode.links` and `SequenceCursor` in
`renderer/layout/sequence.wf` and `module.wfm`. The brief's approximately 280-byte
node / 130-byte output figures are historical observations, not sizes measured
in this exercise.

```wf
fn links_value(links: &Links) -> result: Links reads(links) {
  let value = links^;
  return value;
}

fn collect_heights(scene: &Scene, selection: &Selection, destination: &[u32]) -> result: unit reads(selection), reads(scene.entries[selection.members].links), writes(destination) contract {
  requires selection_for(selection, scene);
  requires destination^.len == selection^.keys.inner.len;
} {
  let count = destination^.len;
  for (at in 0_u64..count) {
    let key = selection^.keys.inner[at];
    let links = links_value(links: &scene^.entries[key].links);
    set destination^[at] = links.height;
  }
  return unit;
}

fn leaf_baseline(scene: &Scene, key: Key) -> result: i64 reads(scene.entries[key].leaf.baseline) contract {
  requires live_entry(scene, key);
} {
  let baseline = scene^.entries[key].leaf.baseline;
  return baseline;
}
```

The loop writes only `destination[at]`; selection/index reads are read-only.
The certified membership proves C2 lookup safety across the helper call. The
helper returns `Links`, not a reference, and EFF-5 sees just that field's path.
The last function goes further: it copies one scalar from one Summary, not that
Summary or Entry. The caller can independently write a disjoint Summary field
when its effect relation permits it; overlapping writes still conflict.

Cost per selected entry: selection-key load, page-descriptor load, requested
group loads, and output store. No per-access recursive page descent, record
snapshot or full-entry memmove is semantically required. In contrast, taking an
owned `Entry` as the helper's parameter would still copy a whole copyable Entry;
C2 does not make that mistake free. Physical AoS cache traffic remains F3/F8's
measurement question. A column layout is unnecessary for the proof or the
field-copy semantics and is not asserted to be automatically better.
