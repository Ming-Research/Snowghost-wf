# W2 — propagate one changed output

HYPOTHETICAL: C1/C2. Uses W3's `translate_selected` and the W1 ordered-index
library. Model restriction: exact, nonnegative ordinary-flow extents; the
preflight checks every ancestor's applicable domain before this mutation starts.
There is no success fallback for an unsupported transfer.

Source lines: 39. Original: `renderer/layout/boundary.wf`, 1,037 lines;
`boundary_sequence_update`, `boundary_owner_update`, `propagate_boundary` and
`same_transfer` provide the behavior. `splice_boundary.wf` adds seam settlement.

```wf
fn propagate_one(scene: &Scene, change: BoundaryChange) -> result: unit writes(scene) contract {
  requires scene_valid(scene);
  requires boundary_change_ready(change, scene);
  ensures scene_valid(scene);
} {
  let owner = change.owner;
  let changed = change.entry_key;
  let output = change.output;
  let shift = change.shift;
  loop {
    let before = owner_summary(scene: scene, owner: owner);
    repair_leaf_summary(scene: scene, owner: owner, entry_key: changed, output: output);
    if shift != 0_i64 {
      let later = collect_after(scene: scene, owner: owner, entry_key: changed);
      translate_selected(scene: scene, selection: &later, delta: shift);
    }
    let inside = owner_index_summary(scene: scene, owner: owner);
    let after = lift_summary(scene: scene, owner: owner, inside: inside);
    store_owner_summary(scene: scene, owner: owner, value: after);
    let same = same_summary(first: before, second: after);
    if same {
      return unit;
    }
    match owner {
      Root() => {
        return unit;
      }
      Block(key: block) => {
        let parent = scene^.payloads[block].parent;
        let back = scene^.payloads[block].back;
        let next_shift = after.extent - before.extent;
        set owner = parent;
        set changed = back;
        set output = after;
        set shift = next_shift;
      }
    }
  }
}
```

`boundary_change_ready` is an arithmetic/semantic preflight relation, not a
fresh tree-validity scan. It checks the actual ancestor path's clamp/margin/
width/float conditions in a production implementation, as `boundary_path_ready`
does. In this bounded model, all extents and origins are in the declared exact
range, including the resulting translations. Extents are nonnegative and at
most `2^30`, so their difference fits i64. The translation callee also owes its
origin-addition domain. Size equality alone cannot stop propagation: baseline
and intrinsic-width changes are included by `same_summary`, and propagate with
zero shift. Each new shift is derived from this owner's actual output difference,
not blindly reused from the initial entry.

`collect_after` collects only direct later entries in the current owner's
index, using subtree counts to skip earlier subtrees. Its Selection is distinct
and contains no nested descendants. Moving a block therefore changes one local
origin; its descendants' owner-relative origins stay valid. Earlier entries,
owner summary and direct sibling targets are distinct supports. The selection
is dropped before walking to the next owner, so there is no live stale-order
certificate across a topology edit (there is no topology edit here anyway).

The outer loop is not parallel: each parent's result needs the changed child's
new summary. Its parent chain strictly decreases forest depth. Upward AVL repair
has its own child-to-parent dependency. The suffix scatter inside each iteration
is parallel by W3's inverse proof. Collection is a balanced disjoint-range
traversal; it is data extraction, not an injectivity verification pass.
For ancestor owners with sizes `n_a` and moved direct-sibling counts `s_a`, work
is `O(sum(log n_a + s_a))`, plus the already required semantic preflight. It
neither scans all payloads nor re-derives a level list on every ancestor.
