# W1 — stable ordered entries

HYPOTHETICAL: C1/C2 and the checked library in [design.md](../design.md).
This fragment lives in the library module that owns `Scene`, so it may open the
cross-table invariant internally. Allocation/preflight errors precede changes to
live entries. The source models a leaf insertion/removal; removing a block's
whole nested subtree is W6. `Body` here is an unlinked leaf paragraph or child
payload, with no references into another Scene.

Source lines: 97. Original: `renderer/layout/sequence.wf`, 1,106 lines;
`insert_before`, `remove`, and `sequence_select` are the comparison, including
the AVL helpers and paged access they call. This is not 1,106 lines of replacement.

```wf
fn insert_leaf(scene: &Scene, owner: Owner, before: Option<Key>, body: Body, output: Summary) -> result: Result<Key, StorageError> writes(scene) contract {
  requires scene_valid(scene);
  requires unlinked_leaf(body);
  ensures scene_valid(scene);
} {
  let plan = propagate insertion_plan(scene: scene, owner: owner, before: before, body: &body, output: output);
  let entry_space = propagate reserve::<Entry>(store: &scene^.entries, count: 1_u64);
  let payload_space = propagate reserve::<Payload>(store: &scene^.payloads, count: 1_u64);
  let entry_key = reservation_key(space: &entry_space, at: 0_u64);
  let payload_key = reservation_key(space: &payload_space, at: 0_u64);
  let payload = make_payload(back: entry_key, parent: owner, body: move body, summary: output);
  let item = item_for(body: &payload.body, key: payload_key);
  let entry_value = make_entry(owner: owner, item: item, summary: output);
  emplace::<Payload>(store: &scene^.payloads, space: &payload_space, key: payload_key, value: move payload);
  emplace::<Entry>(store: &scene^.entries, space: &entry_space, key: entry_key, value: entry_value);
  let root = owner_root(scene: scene, owner: owner);
  let repaired = avl_insert(entries: &scene^.entries, root: root, rank: plan.rank, added: entry_key);
  set_owner_root(scene: scene, owner: owner, root: repaired);
  install_inputs(scene: scene, payload: payload_key, input: plan.input);
  census_attach(scene: scene, payload: payload_key);
  return Ok<Key, StorageError>(value: entry_key);
}

fn remove_leaf(scene: &Scene, owner: Owner, key: Key) -> result: Result<unit, StorageError> writes(scene) contract {
  requires scene_valid(scene);
  ensures scene_valid(scene);
} {
  let plan = propagate removal_plan(scene: scene, owner: owner, key: key);
  let root = owner_root(scene: scene, owner: owner);
  let repaired = avl_remove(entries: &scene^.entries, root: root, rank: plan.rank);
  set_owner_root(scene: scene, owner: owner, root: repaired);
  census_detach(scene: scene, payload: plan.payload);
  retire_inputs(scene: scene, payload: plan.payload);
  retire::<Payload>(store: &scene^.payloads, key: plan.payload);
  retire::<Entry>(store: &scene^.entries, key: key);
  return Ok<unit, StorageError>(value: unit);
}

fn select_event(scene: &Scene, owner: Owner, event: u64) -> result: Option<EventPosition> reads(scene.entries[owner.entry_cells].links), reads(scene.owners[owner].root) contract {
  requires scene_valid(scene);
  ensures selected_event(result, scene, owner, event);
} {
  let cursor = owner_root(scene: scene, owner: owner);
  let remaining = event;
  loop {
    let key = match cursor {
      None() => {
        return None<EventPosition>();
      }
      Some(value: found) => {
        give found;
      }
    }
    let links = scene^.entries[key].links;
    let left_events = subtree_events(entries: &scene^.entries, root: links.left);
    if remaining < left_events {
      set cursor = links.left;
    } else {
      set remaining = remaining - left_events;
      if remaining < links.own_events {
        let position = EventPosition(entry_key: key, offset: remaining);
        return Some<EventPosition>(value: position);
      }
      set remaining = remaining - links.own_events;
      set cursor = links.right;
    }
  }
}

fn select_rank(scene: &Scene, owner: Owner, rank: u64) -> result: Option<Key> reads(scene.entries[owner.entry_cells].links), reads(scene.owners[owner].root) contract {
  requires scene_valid(scene);
  ensures selected_rank(result, scene, owner, rank);
} {
  let cursor = owner_root(scene: scene, owner: owner);
  let remaining = rank;
  loop {
    let key = match cursor {
      None() => {
        return None<Key>();
      }
      Some(value: found) => {
        give found;
      }
    }
    let links = scene^.entries[key].links;
    let left_count = subtree_count(entries: &scene^.entries, root: links.left);
    if remaining < left_count {
      set cursor = links.left;
    } else if remaining == left_count {
      return Some<Key>(value: key);
    } else {
      let after_left = remaining - left_count;
      set remaining = after_left - 1_u64;
      set cursor = links.right;
    }
  }
}
```

`insertion_plan` checks owner/before membership and all count/extent increases;
It derives the new immutable input record from the supplied leaf body/output;
`install_inputs` stores it in the matching payload domain and `retire_inputs`
removes only the selected input record. None means insert at the end, never “invalid key means end.” `removal_plan`
checks membership and that the payload is a leaf. Both report invalid input.
Reservations can leave unused vacant capacity on failure; they publish no live
payload. `census_attach/detach` affect only paragraph membership, with swap-removal
of one census key and repair of the moved paragraph's census inverse.
`scene.owners[owner].root` is the logical root place resolved by `owner_root` and
`set_owner_root` to the synthetic root or that block's `Ordered`; it is not a
second runtime owner table.

The AVL operations use the usual single search path and upward height/count/
summary repair. A two-child deletion transplants the successor's **links**; it
does not copy its payload into the deleted slot. Their C1 contracts are the
partition/rotation obligations in design.md. Their bodies are library work,
not a new kernel primitive and not claimed implemented here.

Both `loop`s are intentionally dependent: the next child and remaining rank
come from the current node. Valid-tree membership supplies each dereference;
height strictly decreases, and empty roots terminate. The explicit comparisons
justify both subtractions. Invalid ranks return None. Cost: `O(log n)` cell
accesses, each C2 access constant directory depth, versus a page-tree descent
at every node today. No loop reconstructs liveness, injectivity or parent facts.

Insertion/removal within the same owner change one shared ordered index and
therefore serialize. The shown single-edit API also updates a context-wide
paragraph Census: its complete calls cannot overlap just because owners differ.
For a multi-owner edit, reserve distinct domains first, run owner-local index/
payload changes independently, then apply one checked batch Census delta (the
algorithm in design.md). That avoids a serialized swap-removal for each paragraph.
The final count publication consumes the completed delta. Putting `reserve` or
`census_detach` on shared state in every independent iteration would add an
unnecessary dependency; neither is proposed as a parallel batch operation.
