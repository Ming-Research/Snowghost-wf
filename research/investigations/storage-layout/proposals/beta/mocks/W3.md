# W3 — one sparse selection, two proved consumers

HYPOTHETICAL: C1/C2. Both consumers receive the very same Selection. Its keys are
entry identities, not ranks, and the proof reads the target payload's existing
`back` field through the entry's `Item` enum. The proof schema is:

`i != j -> selection.keys[i] != selection.keys[j]`; if both items name payload
`p`, then `p.back == selection.keys[i]` and `p.back == selection.keys[j]`, a
contradiction. Tags refine payload existence. The membership facts also supply
bounds and current generation, not just distinctness.

Source lines: 163. Original: `prepare_local_widths` in
`renderer/layout/update.wf` (2,442 lines) and `translate_after` in
`renderer/layout/geometry.wf` (the current location, rather than the brief's
update.wf), plus the direct sibling scatter in `boundary.wf`.

```wf
fn collect_after(scene: &Scene, owner: Owner, entry_key: Key) -> result: Selection reads(scene.index_links[owner.entry_cells]), reads(scene.index_root[owner]) contract {
  requires scene_valid(scene);
  requires entry_of_owner(scene, entry_key, owner);
  ensures selection_for(result, scene);
  ensures direct_suffix(result, scene, owner, entry_key);
} {
  let part = owner_index_part(scene: scene, owner: owner);
  let rank = entry_rank(scene: scene, owner: owner, key: entry_key);
  let skip = rank + 1_u64;
  let count = part.count - skip;
  let placeholder = Key(slot: 0_u64, generation: 0_u64);
  let keys = box_array_filled::<Key>(count: count, value: placeholder);
  fill_selected(scene: scene, part: part, skip: skip, destination: &keys.inner[0_u64..count]);
  let made = seal_selection(scene: scene, owner: owner, keys: move keys, part: part, skip: skip);
  return move made;
}

fn fill_selected(scene: &Scene, part: IndexPart, skip: u64, destination: &[Key]) -> result: unit reads(scene.entries[part.members].links), writes(destination) contract {
  requires index_part_for(part, scene);
  requires skip <= part.count;
  requires destination^.len <= part.count - skip;
  ensures ordered_subrange(destination, scene, part, skip);
} {
  let count = destination^.len;
  if count == 0_u64 {
    return unit;
  }
  let split = split_index(scene: scene, part: part);
  match split {
    Empty() => {
      return unit;
    }
    Node(left: left_part, entry_key: key, right: right_part) => {
      let left_count = left_part.count;
      let root_end = left_count + 1_u64;
      let end = skip + count;
      let left_skip = imin(skip, left_count);
      let left_room = left_count - left_skip;
      let left_take = imin(count, left_room);
      let includes_start = skip <= left_count;
      let includes_end = left_count < end;
      let includes_root = band(includes_start, includes_end);
      let own_take = if includes_root {
        give 1_u64;
      } else {
        give 0_u64;
      }
      let right_start = left_take + own_take;
      let right_skip = if skip > root_end {
        give skip - root_end;
      } else {
        give 0_u64;
      }
      fill_selected(scene: scene, part: left_part, skip: left_skip, destination: &destination^[0_u64..left_take]);
      fill_selected(scene: scene, part: right_part, skip: right_skip, destination: &destination^[right_start..count]);
      if includes_root {
        set destination^[left_take] = key;
      }
      return unit;
    }
  }
}

fn two_passes(scene: &Scene, owner: Owner, after: Key, delta: i64) -> result: unit writes(scene.payloads), reads(scene.entries), reads(scene.owners[owner].root), reads(scene.inputs), reads(scene.common) contract {
  requires scene_valid(scene);
  requires direct_change_ready(scene, owner, after, delta);
  ensures scene_valid(scene);
} {
  let selection = collect_after(scene: scene, owner: owner, entry_key: after);
  translate_selected(scene: scene, selection: &selection, delta: delta);
  prepare_selected(scene: scene, selection: &selection, evidence: scene);
  return unit;
}

fn translate_selected(scene: &Scene, selection: &Selection, delta: i64) -> result: unit reads(selection), reads(scene.item_targets[selection.members]), reads(scene.line_state[selection.targets]), writes(scene.origins[selection.targets]) contract {
  requires selection_for(selection, scene);
  requires translations_fit(selection, scene, delta);
  ensures selection_for(selection, scene);
} {
  let count = selection^.keys.inner.len;
  for (
    at in 0_u64..count,
    apart(i, j) {
    }
  ) {
    let entry_key = selection^.keys.inner[at];
    let item = scene^.entries[entry_key].item;
    match item {
      Block(key: block) => {
        let old = scene^.payloads[block].geometry.y;
        set scene^.payloads[block].geometry.y = old + delta;
      }
      Text(key: paragraph) => {
        let has_lines = paragraph_has_lines(payload: &scene^.payloads[paragraph].body);
        if has_lines {
          let old = scene^.payloads[paragraph].geometry.y;
          set scene^.payloads[paragraph].geometry.y = old + delta;
        }
      }
      Child(key: child) => {
        let old = scene^.payloads[child].geometry.y;
        set scene^.payloads[child].geometry.y = old + delta;
      }
    }
  }
  return unit;
}

fn prepare_selected(scene: &Scene, selection: &Selection, proof evidence: &Scene) -> result: unit reads(selection), reads(scene.item_targets[selection.members]), reads(scene.width_inputs), reads(scene.constants), writes(scene.widths[selection.targets]) contract {
  requires selection_for(selection, scene);
  requires immutable_width_inputs(evidence, scene, selection);
  ensures selection_for(selection, scene);
} {
  let count = selection^.keys.inner.len;
  for (
    at in 0_u64..count,
    apart(i, j) {
    }
  ) {
    let entry_key = selection^.keys.inner[at];
    let item = scene^.entries[entry_key].item;
    let target = item_key(item: item);
    let scale = scene^.common.scale;
    let width = width_from_ancestors(inputs: &scene^.inputs, target: target, scale: scale);
    set scene^.payloads[target].geometry.width = width;
  }
  return unit;
}
```

`IndexPart` describes only direct entries of one owner, not nested owners.
`split_index` exports exact counts, disjoint membership and strictly smaller
left/right parts. The range requirement excludes a nonempty destination for an
Empty part. The two recursive calls and optional root write fill disjoint ranges;
min/branch facts prove their endpoint domains. Collection visits only the selected
subtrees and boundary paths, with `O(k + log n)` work. It initializes a key array
before filling, an explicit additional `O(k)` write cost. The placeholder is raw
key data with no membership authority. `seal_selection` is a checked library
constructor: it requires the proven `ordered_subrange` postcondition and current
scene pairing, so it performs no validation scan and cannot accept arbitrary keys. Its Scene
formal is proof-only; its runtime work is moving the key array and storing the
owner descriptor. The collection row therefore reads only index links/root,
not all payloads through an overbroad helper effect.

`item_key`'s verified tag-dependent postcondition binds its result to the exact
entry target; it is a three-arm match, not a lookup. `paragraph_has_lines` reads
only this paragraph's body. The sparse loops never write `.back`, entry `.item`,
live headers, topology or inputs. Thus both the inverse and selection membership
survive each body, the call boundary, and the first complete pass. The untouched
`common.scale` is read inside the second loop on purpose: comparing full field
paths separates it from `geometry.width`; hoisting it is not a proof workaround.
The `evidence` formal is C1's declared erased parameter and has no runtime row.
The caller still owes its predicate. The evidence relation binds the proof-only Scene to the same input domain/version
as the runtime Scene; callers cannot substitute an unrelated store. The
executable `scene.inputs` reads remain
real loads; erasure does not erase the algorithm's width inputs.

`width_from_ancestors` reads immutable **source inputs**, never another target's
new geometry. It follows the parent chain into an iteration-local stack, then
applies width rules from root to leaf. Every stack access is bounded by its
local length and every rule has checked/clamped arithmetic. The chain within
one width calculation is real; calculations for separate targets are independent.
Work is `O(sum ancestor_depth)` and includes duplicated ancestor calculations,
as in the source's independent local-width path. If the required inputs exist
only in mutable geometry, an immutable snapshot or dependency-respecting
reduction is required; an inverse does not remove that dependency. See F4.

Loop verdict: both counted loops have no cross-iteration read/write conflict.
Each proof checks tags and the stored inverse in its appropriate branch;
it does not assert that Block and Text variants occupy disjoint memory without
using their target/tag relation. `+ delta` requires the preflight predicate at
that element. No proof-only arrays, re-derivation loops or unchecked steps occur
in these consumer bodies. Producer and mutator proofs are C1 library obligations.

## A public boundary, with private representation

The three operations above can live in `pkg::stable`. The following is its
hypothetical `module.wfm` excerpt, using exactly the body's signature/contract
spellings. Scene, Selection, Key and Owner are public library types; their
representation fields remain private. The predicates and **logical effect
views** are public C1 exports verified by that module. This explicitly extends
MOD-6; calling a predicate “public” without checking its definition is not enough.

A client in a second module, whose graph lists `pkg::stable`, needs no field
access to Scene or Selection. It can reuse the first call's returned relation
and the two preserving postconditions:

```wf
alias Scene = pkg::stable::Scene;
alias Owner = pkg::stable::Owner;
alias Key = pkg::stable::Key;
alias collect_after = pkg::stable::collect_after;

fn client_passes(scene: &Scene, owner: Owner, after: Key, delta: i64) -> result: unit writes(scene) contract {

```

View definitions are part of the checked provider, not fields clients may write:
`index_links[K] = entries[K].links`; `index_root[owner]` resolves the synthetic
or block root; `item_targets[K] = entries[K].item`; `line_state[K] = payloads[K].body`; `origins[K] =
payloads[K].geometry.y`; `widths[K] = payloads[K].geometry.width`;
`width_inputs = inputs`; `constants = common`. The provider must prove its body
accesses are covered by these views. Public proof-support metadata says which
views preserve each predicate; it reveals no hidden runtime pointer or stored
borrow. Geometry views do not support scene topology or membership predicates,
so the client can frame scene_valid through both calls.

This is a **boundary mock**, not a complete module package or evidence of an
implemented ABI. Attempting to use `evidence` in executable code, misdeclaring a
view's concrete support, or importing private fields must reject. Implementing
and testing that rejection is F2's first prototype obligation.
