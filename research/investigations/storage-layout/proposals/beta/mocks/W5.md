# W5 — document build, bulk close, dependency-only reduction

HYPOTHETICAL: C1/C2. `Builder` is an unpublished stage type, not a falsely valid
Scene. It owns reciprocal entry/payload pairs and per-owner pending key lists.
The supplied Token stream is the document walk's computed flow tokens; styles,
counters and quote state are read/updated by the builder's ordinary walk helpers.

Source lines: 81. Original: `renderer/layout/build.wf` (3,035 lines),
`bulk_nodes` / `finish_sequence` in `sequence.wf`, and `reduce_sequence` /
`publish_boundaries` in `boundary.wf`. Real source collects during the walk and

fn reduce_part(scene: &Scene, part: TreePart) -> result: Summary reads(scene.inputs), reads(scene.entries[part.entry_cells].links), reads(scene.entries[part.entry_cells].item), reads(scene.payloads[part.payload_cells].body), writes(scene.entries[part.entry_cells].leaf), writes(scene.entries[part.entry_cells].total), writes(scene.payloads[part.payload_cells].summary) contract {
  requires tree_part_for(part, scene);
  requires prepared_inputs(part, scene);
  ensures reduced_part(part, scene, result);
} {
  let split = tree_split(scene: scene, part: part);
  match split {
    Empty() => {
      let empty = empty_summary();
      return empty;
    }
    Node(left: left_part, entry_key: key, own: own_part, right: right_part) => {
      let left = reduce_part(scene: scene, part: left_part);
      let right = reduce_part(scene: scene, part: right_part);
      let item = scene^.entries[key].item;
      let own = match item {
        Block(key: block) => {
          let inside = reduce_part(scene: scene, part: own_part);
          let lifted = lift_block(inputs: &scene^.inputs[block], inside: inside);
          set scene^.payloads[block].summary = lifted;
          give lifted;
        }
        Text(key: paragraph) => {
          let leaf = paragraph_summary(body: &scene^.payloads[paragraph].body);
          set scene^.payloads[paragraph].summary = leaf;
          give leaf;
        }
        Child(key: child) => {
          let leaf = child_summary(body: &scene^.payloads[child].body);
          set scene^.payloads[child].summary = leaf;
          give leaf;
        }
      }
      let prefix = join(left: left, right: own);
      let total = join(left: prefix, right: right);
      set scene^.entries[key].leaf = own;
      set scene^.entries[key].total = total;
      return total;
    }
  }
}

`builder_open/text/child` allocate paired fresh entry/payload keys and append
only descriptors to the current owner's pending list; they do **not** incrementally
repair an AVL. Open also pushes a frame. Close pops a checked non-root frame;
`builder_end` rejects an unclosed frame or inconsistent token stream. Early
errors drop only unpublished owned data. A Child token in this storage model carries an already prepared child-context
summary (independent child-context preparation is a prerequisite, not inferred
from a key). W4's explicit `preparation_result` postcondition supplies the missing
paragraph readiness after the successful Bool branch.
Counter/quote state, the nesting stack
and owner-local output order are the walk's dependencies. This ordered walk is
the existing chosen algorithm; the proposal does not establish that arbitrary
counter semantics admit an equivalent parallel scan.

`bulk_finish` is a median divide-and-conquer implementation of the bulk-index
row in design.md: distinct pending keys partition into left, root, right;
recursive halves write disjoint link cells; the root sets parent links and
weights after those results. It does not call W1's `insert_leaf`. Total `O(n)`
index work; per-owner span `O(log n)`. Append growth may copy **pending keys**,
not previously installed payloads. Structural event counts (including a nested
block's Open/Close) are available at Close; semantic summaries wait for preparation.

`tree_split` exports disjoint sets for left/right index subtrees and the root
entry's nested owner tree. Each part contains its descendant entries and their
payloads; the root block payload itself is excluded from the nested part and
handled by the current invocation. This distinction prevents double ownership
of the block's summary. Empty parts have empty write sets.

The two recursion calls and the independent own computation may overlap under
PAR-1 extended with C1 sets. Their first shared dependency is `join`. Each
recursive edge decreases remaining entry count, including descent into a block.
There is no sequential loop over depths: an unrelated deep branch cannot delay
a ready shallow parent's reduction. The final ordered composition preserves
left/own/right operand order; no commutative accumulator or saturating arithmetic
reassociation is claimed. Worst-path span follows actual nested owner/AVL
ancestry, not the total number of owners.
