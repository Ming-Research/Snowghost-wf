M1 step 2: the reverse rule index and the restyle set of a class edit
(Q91's matching half), checked against a full rematch. Host, compiler and
inputs of runs/step1.txt; the style oracle built sequentially from the
commit that adds this record.

What was added
  pkg::css::selectors::class_reaches records, for every class selector and
  every attribute selector on the class attribute of a rule's alternatives,
  which elements around the edited element e a change of that class word can
  make the alternative match or stop matching: e (rightmost compound), its
  descendants, its later siblings, their descendants, or any element (an
  :nth-child of-clause), with the alternative's subject key. A class inside
  :not, :is or :where composes its compound's reach inside the argument with
  the reach of the compound holding the argument. add_sheet stores the
  reaches of every rule in the RuleStore.
  pkg::style::class_restyle gathers the reaches of the edited class (and the
  every-class ones), then flags, one flag per element of e's subtree and of
  the rest of its parent's subtree, the elements those reaches name and
  whose local name, first id or class words carry a wanted subject key.
  pkg::style::rematched compares two match_elements results element by
  element (winners, custom-rule keys, pseudo-elements). The style oracle's
  mode `restyle` runs both for each C or K line of a script and reports the
  set, the rematched elements and those missing from the set.

3. Precision
  A first version gave every class inside a selector-list argument the
  reach of all four directions. html5's
  `p > span:not([class="XXX"])...` then made any class change on any element
  restyle every span after it under its parent: colour sets up to 3350
  elements for one rematched, rootfont sets of 4508 on every edit. Composing
  the argument's own reach brought every colour, fontsize and rootfont set
  to the edited element alone, with the same check result. Sets still
  larger than the rematched elements come from rules that name the class
  and a subject key the reached element carries but whose other compounds
  do not hold (html5 body: 76526 against 75420).
