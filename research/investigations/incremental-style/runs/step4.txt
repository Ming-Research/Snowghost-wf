M1 step 4: the sparse interface from style to layout (Q93). Whitefoot
c3d26643c (pinned by 93601c7), Apple M1 Pro; every build with --cache
build/whitefoot-cache --fragments function under a memory and time guard.

What was added
  pkg::style::restyle reports, besides the elements it visited, `changed`,
  the elements whose computed style or a pseudo-element's changed in what
  layout reads (layout_same: all but colours, the custom-property set and,
  of the background, more than whether it is present, as layout_changes
  compares two runs), and `structural`, whether an input of box construction
  changed (construction_same: display, position, float, overflow, multi-
  column, list marker, content, counter and quote lists, which the kept
  tables intern by value, or which pseudo-elements an element has).
  pkg::style::pseudo_reads_attribute says whether a generated pseudo-element
  of the edited element reads the edited attribute through attr().
  pkg::layout records, with the text units and paths, where each element's
  style is read (StyleUse, by NodeId): the context whose blocks, rows,
  columns, children or paragraphs read it, with the paragraph range, and
  the context it establishes; styles_restyled marks those paragraphs and
  contexts down their paths, falling back to the whole-tree marking for an
  element read by two contexts.
  The layout oracle's C and K edits now run class_restyle and restyle on a
  kept StyleState, refuse a structural edit or one whose generated content
  reads the class (the caller rebuilds), then styles_restyled and update;
  layout_changes, retained_styles and the whole-tree marking no longer run
  for them. B and X edits keep the full style run with structure_changed.
  Styles keeps its eighteen kept-table fields in one private field
  (KeptTables): with them as direct fields, checking pkg::oracle::layout,
  which holds a Styles, passed 6 GB within 31 s on M1 step 1 (it took 13 s
  and 2.5 GB on main); nested, 16 s and 3.2 GB.

1. Identity (incremental-layout/run.sh inc seq; each edit's incremental
   dump against a full rebuild, byte for byte)
  apollo11 all six scripts: colour 60, fontsize 60, rootfont 60, body 26,
    custom 26 edits, every one inc same; classes 80 edits, 72 inc same and
    8 refused, no DIFF.
  html5 and ecma262, the first 10 edits of each script (S lines kept):
    colour, fontsize, rootfont, body, custom 10 inc same each; classes 6
    inc same and 4 refused (edits 5, 6, 9, 10; 5 and 6 toggle `hide`,
    display none), no DIFF.
  The step-3 driver of main (build/m1/base_layout_seq, layout_changes and
  styles_changed) on apollo11 classes refuses the same 8 edits.
  Not run: html5 and ecma262 beyond the first 10 edits per script, and the
  par build.

2. Falsifier: styles_restyled skips the last element of the changed list
  apollo11 fontsize: 6 of 60 edits DIFF. (body: none, since its edits
  change colours only for that element.)
