Chromium probe: does a paragraph with no text have a line when an inline box in it has sides?
Page: body margin 0, font 16px/20px serif, each case a div 200px wide holding only the span.
  span style                         div height   span rectangle (x,y,w,h)
  padding: 0 1px                     20           0,1,2,17
  margin: 0 1px                      20           1,26,0,17
  border-left: 1px solid             20           0,51,1,17
  padding: 1px 0                     0            0,75,0,0
  margin: 1px 0                      0            0,75,0,0
  no style                           0            0,75,0,0
  padding: 0 1px around a nested span with padding: 0 1px    20    outer 0,76,4,17 inner 1,76,2,17
  padding: 0 1px; font-size: 30px    25           0,143,2,33 (the line is as tall as the span's own line-height box, 25px)
  margin-left: -1px; padding-left: 1px   20       -1,181,1,17
A nonzero margin, border or padding on a side of an inline box makes the line exist; the same on top or bottom only does not (CSS 2.2 9.4.2). apollo11's navbar abbreviation lines (div with <span style="padding: 1px"></span>) measure 15.03px high in the reference.
