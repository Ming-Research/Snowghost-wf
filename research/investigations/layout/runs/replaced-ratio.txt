Replaced elements with an auto height (Chromium, headless)

Probe: build/probes/rv.html, a div around each element, vertical-align top; the element's box
(width x height) with the CSS given below.

  element, attributes, CSS                                    Chromium    ratio of the attributes
  video width=250 height=188, height:auto                      250 x 188   yes
  video width=250 height=188, width:100px; height:auto         100 x 75.19 yes (100 * 188 / 250)
  video, width:100px; height:auto                              100 x 150   no, the natural height
  video width=250, height:auto                                 250 x 150   no
  video width=250 height=188                                   250 x 188   given
  iframe width=250 height=188, height:auto                     254 x 154   no (2 px borders)
  iframe width=250 height=188, width:100px; height:auto        104 x 154   no
  svg width=250 height=188, width:100px; height:auto           100 x 75.19 yes

An img, a video and an svg with both a width and a height attribute take their ratio (HTML
15.5.4, 15.5.6 and 15.5.9 map the two attributes to aspect-ratio: auto w / h); any other replaced
box has no ratio, and an auto axis takes the natural size (300 by 150, CSS 2.2 10.3.2) instead of
the scaled one. apollo11's three videos are 188 px high for Chromium and were 125 px here, which
moved the sections after them by 63 px.
