Chromium probe for an absolutely positioned box whose width or height is a percentage
(tests/layout/flow-cases.html, last section; dumped with node tests/layout/layout_oracle.mjs dump):
  containing block: position:relative div, width 150px, padding 4px 0, one 17px line -> 150x26 border box
  input[type=checkbox], position:absolute; width:100%; height:100%; margin:0; padding:0 -> 150x26 (the padding box of the containing block)
  div, position:absolute; width:50%; height:50% -> 75x13
The percentages resolve against the containing block's padding box, so a box that sets either one is laid out again once the containing block's height is known.
